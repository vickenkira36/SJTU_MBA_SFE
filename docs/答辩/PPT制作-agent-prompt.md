## 三、设计规范

**版式基调**：上海交通大学配色——主色交大红 `#A4283C`、辅色深红 `#7E1F2E`、文字近黑 `#333333`、底纹浅灰 `#F2F2F2`、留白为白。中文字体微软雅黑，数字与英文可用同族无衬线体。16:9 幅面。

如果我另外提供了学校 PPT 模板文件，直接套用其母版与配色，以模板为准；没提供就按上述配色自建，风格保持学术、克制，不要用渐变、阴影、立体等装饰效果。

**四条必须遵守的排版规则**，它们是针对上一版 PPT「内容单薄」的直接修正：

1. **标题写成断言，不写标签。** 写「湖南：均衡度改善 58.7%，同时保住 87.4% 客户关系」，不写「主样本结果」。评委扫标题就能拿到结论。
2. **凡是配图的页，图旁必须有解读文字**，分两到三层写：*这张图在看什么* → *读出什么数字* → *所以说明什么*。禁止一张图配三个裸数字了事。
3. **竖长图（fig4-1）不许居中甩。** 必须左图右文两栏排，否则两侧大片留白、图内文字小到看不清。
4. **表格页必须有结论。** 要么标题是结论，要么表格下方/旁边有一行断言。禁止只摆数字让评委自己算。

**信息密度**：内容页 3-5 条要点，每条 6-16 字的短语，可带一句灰色小字子说明。宁可密，不要空。但不写「这说明」「这意味着」这类叙述句——分析留给口头讲述。
