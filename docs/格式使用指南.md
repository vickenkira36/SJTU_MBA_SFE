# SJTU 学位论文格式工具链使用指南

本指南说明如何用本仓库的工具链，把 Markdown 论文一键生成符合上海交通大学
学位论文格式要求的 Word 文档（封面、校徽、目录、分章页眉、分段页码全部自动）。

格式参数对齐学校官方《论文模板（word）》：A4、上 3.5 / 下 4.0 / 左右 2.5 cm
页边距，正文小四（12pt）宋体，标题黑体，1.5 倍行距。

---

## 一、环境依赖

```bash
# macOS
brew install pandoc
pip3 install python-docx

# 渲染图（可选，仅在重新生成 figures 时需要）
brew install graphviz
```

字体：正文宋体、标题黑体、西文 Times New Roman——这些是 Word 打开时按样式
名解析的，macOS / Windows 自带，无需额外安装。

---

## 二、三步复用到你自己的论文

### 第 1 步：改封面与页眉信息

编辑 [`docs/thesis-meta.json`](thesis-meta.json)，这是唯一需要改的配置文件：

```json
{
  "title": "你的论文题目\n（用 \\n 换行，标题过长时分两行）",
  "fields": [
    ["姓　　名", "你的姓名"],
    ["学　　号", "你的学号"],
    ["导　　师", "导师姓名　职称"],
    ["院　　系", "你的院系"],
    ["学科/专业", "你的专业"],
    ["申请学位", "你的学位类型"]
  ],
  "date": "答辩年月"
}
```

字段标签里的全角空格（`姓　　名`）用于对齐，可保留。

### 第 2 步：换正文

把你的论文写进 [`docs/thesis.md`](thesis.md)，保持以下结构约定：

- `# 摘要` / `# Abstract` —— 一级标题，放在最前（封面后、目录前）
- `# 第一章 绪论` / `# 第二章 ...` —— 各章用一级标题，**必须以"第X章"开头**
- `## 1.1 小节` / `### 1.1.1 子节` —— 二、三级标题
- `# 附录 A ...` / `# 参考文献` —— 同样用一级标题
- 表格用 Markdown 表格语法；图用 `![图 X-Y 标题](figures/xxx.png)`
- 引用用 `[@bibkey]`，文献登记在 [`references.bib`](references.bib)

分章页眉靠"第X章"前缀识别，请勿改这个命名规则。

### 第 3 步：一键生成

```bash
bash scripts/build-docx.sh
```

产物为 `docs/thesis.docx`。

---

## 三、生成后在 Word 里更新域（重要）

文档里的**目录**和**页码**是 Word 域，首次打开需要更新一次：

- **自动**：用 Word 打开时若弹窗"是否更新域"，点【是】，目录与页码一并生成
- **手动**：`Ctrl+A` 全选 → `F9`（Mac 为 `fn+F9`）；目录那行单独右键 →
  更新域 → 更新整个目录

> 为什么不能预先生成好页码？页码由 Word 排版引擎按实际分页计算，
> 任何脱离 Word 的工具都算不出来——这是学位论文目录的标准做法。

## 四、格式规格一览（对齐官方模板）

| 项目 | 规格 |
|------|------|
| 纸张 | A4（21 × 29.7 cm） |
| 页边距 | 上 3.5 / 下 4.0 / 左 2.5 / 右 2.5 cm |
| 正文 | 宋体小四（12pt），1.5 倍行距，首行缩进 2 字符 |
| 一级标题 | 黑体三号（16pt）加粗居中，章前分页 |
| 二级标题 | 黑体四号（14pt）加粗左对齐 |
| 三级标题 | 黑体小四（12pt）加粗左对齐 |
| 页眉 | 左「上海交通大学硕士学位论文」 + 右「当前章名」，底部横线 |
| 页脚 | 居中页码 |
| 页码分段 | 封面无页码；摘要/目录用罗马数字 Ⅰ Ⅱ；正文从第一章起阿拉伯数字 1 重新计数 |

## 五、工具链文件职责

| 文件 | 作用 |
|------|------|
| `docs/create_template.py` | 生成 `antai-template.docx`——定义字体/字号/页边距/页眉页脚样式。改格式规格时改这里，然后重跑它 |
| `docs/antai-template.docx` | pandoc 的样式参考文档（由上者生成，勿手改） |
| `docs/post_process_docx.py` | pandoc 转换后处理：插封面+校徽、目录 TOC 域、按章分节并写各章页眉、分段页码、表格 AutoFit |
| `docs/thesis-meta.json` | 封面/页眉的具体文字内容（复用时改这个） |
| `scripts/build-docx.sh` | 串起 pandoc + 后处理的一键脚本 |
| `docs/superscript-cite.lua` | 把文献引用渲染成上标 [1] 样式 |
| `docs/gb-t-7714-2015-numeric.csl` | GB/T 7714-2015 国标数字引用格式 |

## 六、常见问题

**Q：页眉右侧章名显示"错误!使用开始选项卡..."？**
A：本工具链用的是**静态章名**（按章分节写死），不会有这个报错。该报错出现在
用 STYLEREF 域的方案里——中文 Word 对英文样式名 STYLEREF 匹配不稳定。本工具链
已规避。

**Q：封面装不下一页 / 内容溢出到第二页？**
A：题目过长时在 `thesis-meta.json` 的 `title` 里用 `\n` 手动分两行。仍溢出可
适当精简字段，或在 `post_process_docx.py` 的 `_build_cover_elements` 里调小间距。

**Q：改了 thesis-meta.json 但 docx 没变？**
A：要重跑 `bash scripts/build-docx.sh`。docx 是生成产物，不会自动跟随 JSON 更新。

**Q：目录里的页码不对 / 还是占位文字？**
A：在 Word 里右键目录 → 更新域 → 更新整个目录（见第三节）。
